# Vibin Tote Bag photos

Drop the real photos here with these exact names, then set `ready: true` on the matching slot in
`app/lib/product-extras.mjs`. Until then the product page shows a labelled "Photo coming soon" tile.

| Slot | File | View |
| --- | --- | --- |
| 1 | `tote-01-back.webp` | Back view |
| 2 | `tote-02-inside.webp` | Inside view (straight down into the open bag) |
| 3 | `tote-03-magnetic-snap.webp` | Magnetic snap closure close-up |
| 4 | `tote-04-what-fits.webp` | What fits (bag upright and full) |

Use 3:4 portrait or square, at least 1200px on the short side, under 500 KB each. `.webp` preferred;
if a file is `.jpg` or `.png`, change the `file` name in `product-extras.mjs` to match.
